# 🕌 Namaz Vakti ve Fıkıh Asistanı (Hugging Face Space)

Bu Space, **Custom Jinja2 Chat Template** ve **Tool-Calling Destekli AI Asistan** projesinin canlı ve ücretsiz çalışan web arayüzüdür.

## 📌 Özellikler
- **Public API (Read)**: Aladhan REST API ile şehir bazlı ezan ve namaz vakitleri tespiti.
- **SQLite Veritabanı (Write & Read & Search)**: Soru kaydetme, listeleme ve kelime arama.
- **Trace Logs**: Arka planda çalışan Custom Jinja2 sohbet şablonu çıktısını ve fonksiyon çağrı izlerini canlı görüntüleme.
- **Maliyetsiz İstemci (Zero-Cost)**: CPU sunucularda %100 ücretsiz ve kesintisiz çalışma.
